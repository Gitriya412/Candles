# LUMORA — Light Up Your Moments
### Premium Handcrafted Candle Brand & Editorial E-Commerce Showcase

A luxury, editorial-style frontend website designed specifically for artisanal candle makers and boutique lifestyle studios.

---

## 🕯️ Brand Identity
- **Brand Name:** LUMORA
- **Tagline:** Light Up Your Moments.
- **Palette:** Warm Cream (`#F8F1E7`), Terracotta (`#C66B4E`), Sage Green (`#829477`), Dusty Rose (`#D89A9B`), Lavender (`#A18BB9`), Amber Gold (`#C68B3E`), Deep Burgundy (`#713C43`), Warm Sand (`#E8CFA8`), Espresso Brown (`#382B24`).
- **Typography:** Cormorant Garamond & Italiana (Editorial Serif) paired with Plus Jakarta Sans (Modern Sans-Serif).

---

## ✨ Features & Architecture

1. **Announcement Bar:**
   - Free shipping indicator above ₹999 with dynamic promo code `GLOW10` for 10% off.

2. **Sticky Navigation:**
   - Glassmorphism backdrop blur on scroll, active section indicator, interactive shopping bag drawer with live counter badge, and responsive mobile menu.

3. **Hero Section:**
   - High-impact editorial composition featuring colourful handmade candles in terracotta, sage, dusty pink, amber, and lavender.
   - Floating small-batch badges and quick color palette preview.

4. **Shop by Collection (5 Distinct Collections):**
   - *Floral Dreams*, *Earthy Elements*, *Golden Hour*, *Sculpted Stories*, and *Gift of Glow*.
   - Clicking any collection card automatically filters the products and smoothly scrolls to the shop.

5. **Bestselling Candles Catalog:**
   - Full implementation of the 6 signature candles with authentic colourful photography:
     - **Rose Petal** (₹499) — Dusty Rose Soy
     - **Forest Whisper** (₹599) — Sage Green Botanical
     - **Vanilla Sunset** (₹549) — Amber Gold Glow
     - **Lavender Haze** (₹649) — Pastel Lavender
     - **Cinnamon Ember** (₹599) — Terracotta Russet Clay
     - **Midnight Bloom** (₹749) — Deep Burgundy Reserve
   - Category filtering (All, Floral, Earthy, Golden, Sculpted, Gift Sets).
   - Color swatch filter (Dusty Rose, Sage, Amber, Lavender, Terracotta, Burgundy).
   - Dynamic sorting (Featured, Price: Low to High, Price: High to Low, Rating).
   - Quick View modal trigger, Add to Cart with live feedback, and Wishlist toggling.

6. **Quick-View Product Modal:**
   - High-resolution gallery thumbnails, color swatch indicator, Fragrance Pyramid breakdown (Top, Heart, Base notes), candle specs (Wax, Burn Time, Wick, Vessel), quantity controller, and direct bag addition.

7. **Slide-Over Shopping Bag Drawer:**
   - Cart counter badge, item list, quantity adjustment, remove item.
   - Free shipping progress bar (target ₹999).
   - Coupon code redemption (`GLOW10` for 10% off).
   - Simulated Checkout modal with order confirmation receipt.

8. **Our Story & Brand Philosophy:**
   - Editorial split layout with candle-making photography, small-batch 48hr curing process, and milestone counters.

9. **Why Choose LUMORA:**
   - 4 bespoke feature cards: *Handcrafted with Love*, *Beautiful Fragrance Blends*, *Premium Quality Ingredients*, *Unique Artistic Designs*.

10. **Custom Orders & Bespoke Gifting:**
    - Rich terracotta backdrop.
    - Showcases *Wedding favours*, *Birthday gifts*, *Anniversary gifts*, *Corporate gifting*, and *Personalized candles*.
    - Interactive custom candle configurator with direct WhatsApp order generation.

11. **Customer Testimonials:**
    - 3 detailed verified buyer cards with real scenarios (wedding clients, interior stylists, wellness doctors).

12. **Instagram Lifestyle Gallery:**
    - 6 aesthetic lifestyle grid photos with hover statistics.

13. **Newsletter Section:**
    - "Get Inspired. Stay Glowing." with frontend email validation and success voucher popup.

14. **Contact Section & Studio Atelier:**
    - Studio address, phone, email, opening hours, and validated contact form.

15. **Candle Care & Ritual Modal:**
    - Educational guide on wick trimming, preventing candle tunneling, max burn time, and repurposing jars.

16. **Floating WhatsApp Concierge:**
    - Instant chat button with prefilled inquiry message (+91 98765 43210).

## 🚀 Running the Project Locally

```bash
# 1. Install dependencies (if not already done)
npm install

# 2. Start the local development server
npm run dev

# 3. Build for production
npm run build
```
